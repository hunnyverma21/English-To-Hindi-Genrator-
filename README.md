# English to Hindi Translator

A beginner-friendly web app that translates English text into Hindi.

## Features
- English input and Hindi output panels
- Translate, clear, and copy buttons
- Responsive layout for mobile and desktop
- Uses the MyMemory translation API, so an internet connection is required

## How to run
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Enter English text and click **Translate to Hindi**.

## Notes
- Translation is provided by an external service and may not always be perfect.
- Do not enter passwords, private, or sensitive information.
- For longer text, the translation service may have request limits.
